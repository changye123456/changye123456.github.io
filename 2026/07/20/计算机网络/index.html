1.1internet

什么是internet

网络(边缘、中心、接入网)，互联网并非唯一网

internet是很多网络组成(链路层(点与点)、网络层(端到端，可能会丢与错误)、传输层(解决信息丢失)、应用层(游戏、直播)

网络(节点和边)->计算机网络(主机是数据的源节点、数据交换节点(转发节点)(交换器【链路层】、路由器【网络层】))->互联网

边(接入链路(主机与交换器的边)Access Network，骨干链路(交换器与交换器)Backbone Network)

协议是标准、规则()，对等层的实体，协议有格式(语法与语义)、次序、动作

互联网(以一簇协议支撑的网络，端系统【end system、host（主机）】(操作系统、应用)，网络交换设备、link(链路))->从服务角度分布式应用进程与基础设施(面向连接、无连接)

internet(企业网)

1.2网络边缘

互联网分为网络边缘(主机、分布式应用)、网络核心(交换系统，交换器与交换器)、[接入网、物理媒介]（交换器与主机）

应用的通信模式:cs模式(客户端与服务器)、p2p(peer同等体，既可作为客户端也可以作为服务器)

采取基础设施面向连接的服务(基础设施相互连接，实例如TCP连接)

udp直接传输，不可靠、无连接、无流量控制、无拥塞控制

tcp流量控制、拥塞控制、缓存

1.3网络核心

线路交换（电路交换）(信令系统，链路挑选不用的pices[线路]，源与目标中独享)

->频分(Frequency-division multiplexing，长度较长，波段可分)->时分(TDM)->波分(WDM，光通信)

分组交换要用就用全部先分组，在节点将分组所有数据全存为packet再转发[存储转发](排队延迟和丢失)(统计多路复用，A与B使用链路不固定)bps

存储-转发

1.数据包网络(每个分组都携带目标地址，无需建立连接，有数据就传)

2.虚电路网路(要握手，建立虚拟线路，分组携带虚拟线路号)

例如有35个个用户，每个人传输由0.1概率传100kbps的消息，总宽带是1Mbps，那么1M/100k = 10,那么一下子全传挂的概率是1-Σpn*(1-p)^35- n（从0求到9），占用为1会直接服务挂掉

1.4 接入网和物理媒体

住宅接入

modem，电话线调频解调通信(4khz下)

dsi(digitial subscriber line)通电话的hz上更发杂的调试解调

线缆网络(电视台，有上行【共享】与下行[私有],往上是光纤，往下是点电缆)

企业交换网络(Enthernet)

无线接入

无线LANs(局部)

广域无线接入

物理媒体

媒体分为导引型媒体(有形)和非导体型媒体(无形)

导引型媒体(有形)：双绞线(tp)，同轴电缆，光缆

非导体型媒体(无形)：开放空间传电磁波->地面微波、LAN(如wifi)->wide-drea(eg蜂巢)，卫星

1.5 Internet机构和ISP

关系比较密集的网络成为isp(互联网是一堆isp通过路由器来年再一起，网络的网络)

端系统通过接入Isps(Internet Service Providers)连接到互联网

设置isp —通过access net— >global isp(global isp也有竞争与合作，ixp[exch，交换点，网间的流量交换])

regional net

icp(internet context providers)data center（数据中心，用专用线缆将数据中心连接，为了向全球各个地方提供稳定服务）

local isp->regional isp->global isp

连接

pop:高层isp连接用户的isp

对等接入:两个isp对等接入，不涉及费用结算

ixp:多个isp对等接入

icp自己的专属网络:通时和各级isp互连

1.6 分组延迟、丢失和吞吐量

分组到达的速度超过了链路输出的能力(延迟:排队延迟，处理延迟【确定】，传输延迟[L * （1/链路宽度）]，，传播延迟[d/s])

排队延迟:取决于流量强度(L*a/R)，必须在0~1之间

ICMP(报文控制协议)

丢失

输出队列(链路缓冲区有限)满了丢失->1.主机传2.上个路由器传3.丢弃

吞吐量:源端和目标端之间的传输速率(瞬间吞吐量，平均吞吐量)->瓶颈链路(决定吞吐量的链路)

1.7协议层次与多模型

模型分层(上层通过下层与不同协议实体交互，交换pdu(protocol data unity)协议数据单元)，协议是水平关系，协议基于下层服务实现，为了更好的向上级服务，

服务用户，服务访问点(SAP(service Acess point),区分服务上层用户，服务者通过）

原语[向上层告诉服务的类型，高层使用底层提供的服务以原语进行交互，类似于讲话用的原语]

服务类型(垂直)

面向连接的服务(连接->连接确认)，无连接的服务(用udp服务，不需要握手建立连接)

数据单元(DU)

SDU（上一层是服务数据单元）+ICI(接口控制信息) = IDU

协议实体见通过pdu(n-header + SDU)交流

pdu(应用层叫应用报文，传输层为报文段，网络层成为分组(无连接是数据帧(frame))，链路层叫针)

分层处理的好处

1.概念化:结构清晰，便于标示网络组件

2.结构化:模块化更易于维护和系统升级

Internet协议栈参考模型

1.应用层(报文message):网络应用

2.传输层(报文段segment):主机之间的数据传输

3.网络层(数据段不分组datagram(数据报),分组的叫packet):为数据报从源到目的选择路由

4.链路层(帧frame)：相邻网络节点间的数据传输(以帧为单位的数据)

5.物理层(bit)：在线路上传输bit

部署在端系统中

客户端:maybe动态ip，不能直接与其他客户端通信

p2p(对等体)：任意系统可以相互通信

混合体

进程通信

进程:在主机上运行的应用程序

同一主机内使用进程间通信机制通信(操作系统定义)

不同主机通过message(报文)通信

客户端进程，服务器进程

解决的问题

标识与寻址

Port端口号

传输层-应用层怎么连接(scoket api)

要交流的信息:要传的报文，发给谁，谁发的(主机ip，进程的端口号)

tcp socket[套接字](本地和对方的ip和端口的本地表示，对方不知道，表示一次会话)

udp socket(只代表本地ip和接口)

怎么定义报文的格式与解释，如何使用服务

应用程序可以用end point(端节点)表示

应用层协议:定义不同端系统如何交换报文open(RFC文档定义)，私有(协议不公开)

传输层向应用层服务的衡量标准:1.数据的丢失率2.延迟3.安全性4.吞吐

物理层

概念

在连接各种计算机的传输媒体上传输数据的比特流

特性

1.机械特性(定义物理连接的特性)

2.电器特性(规定传输的二进制位)

3.功能特性(某一电平的意义，接口信号线的用途)

4.规程特性:定义物理线路的工作规程和时序关系

端–信道,数字信号–>调制解调器-模拟信号->广域网–模拟信号->调制解调器–数字信号–>端

码元:用一个固定时长的信号波形（数字脉冲），一个码元携带log2V个bit(v为进制)

码元的传输速率(波特率)，单位时间传输的码元的个数，单位是Baud(B)

消息、数据(数据是消息的实体，0/1)、信号(数据的电气或者电磁表现)

信道:表示某个方向传递信息的实体

基带信号:来自信源的信号->变身:1.编码2.带通调制(变成模拟信号)

归零信号:高1低0，1的后半段归0

非归零信号:高1低0，1的后半段不归0

曼彻斯特编码:前高后低为1，前低后高为0

差分曼彻斯特编码:跳变为0，不变为1

常见的调制

1.调幅

2.调频

3.调相

数据传输速率计算

奈氏准则:(无噪声)，极限码元传输速率是2 W Baud,w是信道带宽，单位是HZ，V有多少个码元（每个码元离散电平的数量）,传输速率2Wlog2V(b/s)

香农定理:有噪声情况下,传输速率W * log2(1+S/N)（b/s），信噪比(db) = 10log10(S/N)

信道复用

多个信号组合在物理信道上进行传输

传输介质

导引型:双绞线(T->100MBPS)、同轴电缆、光纤

非导引型:无线电波(全方向，穿透性强)、微波(固定方向传播)、红外线、激光

物理层

中继器、集线器

宽带接入

非对称用户线(ADSL)

光纤混合网HFC(光纤、同轴电缆)

光纤到FFTX

数据链路层（OSI模型的第二层）

位于物理层和网络层之间，在广播式多路访问链路(局域网)，由于存在介质征用，还可以细分为MAC(介质访问控制)子层和逻辑链路控制(LLC)

传输帧(帧首部 帧的数据部分(ip的数据报，最大传输数据MTU，最大1500) 帧的尾部)->帧首尾作用是帧界定(帧开始结束)，含控制信息

链路层的信道类型:

1.一对一:点对点信道

2.一对多:广播信道

要解绝的问题

封装成帧

透明传输(无论什么比特组合都能在链路上传输，用字符/字节填充解决透明传输问题[转义字符])

差错检测(位错、帧错)->位错解决方法是CRC(循环冗余检测CRC，冗余码【FCS帧检测序列】为要传数据/生成多项式，先补上多项式的阶数，除以多项式异或，)

协议

PPP协议(拨号电话接入因特网，其实现透明传输的方法为，异步传输|面向字符为字节填充法,同步传输|面向bit:零比特传输[标志字段连续5个1后面添加0])

CSMA/CD协议(载波监听多址接入/碰撞检测，CS是载波侦听/监听在发送数据和发送数据时检测总线上是否有其他计算机在发送数据，MA表示多点检测[多个设置在一个线上]，CD是碰撞检测[冲突检测])

局域网(LAN,local Area Network)

1.覆盖的地理小

2.使用专门铺设的传输介质进行联网

3.延迟短、可靠性高

4.既有广播功能

LLC负责是被识别网络层协议，进行封装

MAC负责帧的访问/卸载，寻址和识别

以太网

使用CSMA/CD协议

计算机接入局域/以太网靠的是适配器(网络接口/网卡)

每个适配器有全球唯一的48位二进制地址，前24位代指厂家，后24位由厂家自己制定，一般是6组两个8进制位

设备

网桥与交换机(直通式交换机查完地址立刻转发，存储转发式在高速缓存中检测，功能VLAN虚拟局域网以以太网帧进行交换)

冲突域:在一个冲突域中的每一个节点都能收到帧，相同时间一个设备发送的信息的范围

广播域：网络中能接收到任意设施发出的广播帧的集合，单站点能收到信号的范围

链路层能隔离冲突域(一个端点一个冲突域，但是隔离不了广播域)

网络层

定义

在osi(open system interconnection)的第三层，提供路由和寻址功能，有一定的拥塞控制和流量控制能力，由于tcp/ip协议中网络层由IP协议规定和实现，故又称iP层

提供灵活的无连接的数据服务，将分组(IP数据报)从源端传到目的端，可由多种异构网络互联组成

ip数据报格式

首部+数据段(TCP+UDP段)

首部由固定部分和可变部分组成

版本占4字节，首部长度单位为4字节(例如1111为10进制的15，表示长度为15*4)

总长度为头长度+数据的长度，

标识如果数据报超过1500字节放不到帧中，标识标识是否是一个数据报

标志只有中间位(DF,Don`t Fragment,DF = 1禁止分片，DF=0允许分片;最低为MF,More fragment, MF = 1表示后面还有分片，MF = 0表示后面没有分片)

片偏移，某片在原分组的相对位置，以8B为单位，相对于原来的数据的开头(不含首部)

ip地址分类

分类的ip地址(最基本的编址方法)(点分十进制0~255，172.255.255.255)

32位的网络地址分为网络号和主机号

主机号全为0:为本主机连接单个网络地址

主机号全为1:该网络上所偶有的主机(广播地址)

A类(1~126，),网络号第一位固定为0

B类（128~191），网络号前两位固定为10

C类（192~223）网络号前两位固定为110

D类的组播

网络地址转换NAT(Network Address Translation),解决

子网的划分(最基本的编址方法的改进)

子网的掩码(网络号全为1，本机号全为0，与地址只进行位与)

主机号的部分划为子网

无分类编制CIDR(比较新的无分类编址)

网络号和子网号连接成网络前缀

协议

ICMP(互联网控制消息协)发在IP中发送消息送控制信息

ARP(Adress Resolution Protocol，地址解析协议)在数据链路层，完成ip地址到MAC地址的映射

IGMP(互联网组管理协议， group management protocol)

传输层

端到端的信息传递，提供面向连接的数据支持、可靠性、流量控制

进程和进程的逻辑通信，靠套接字(Socket)找到应用进程，可对报文进行差错检测

TCP(面向连接(虚连接)的传输控制协议，有发送缓存和接受缓存)，数据偏移以4B为单位

第一次握手SYN为1，seq(学列好)为x二次为SYN (同步请求)= 1，ACK = 1，seq为y(随机)，ack = x+1

三次握手SYN (同步请求)= 0，ACK = 1，seq为x+1，ack = y+1

四次分手 先是客户端分手(FIN = 1,seq = n)服务器同意(ACk = 1,seq = v,ack = u+1)，之后服务器分手(FIN = 1ACk = 1,seq = w,ack = u+1)

之后客户端同意(ACK = 1，seq = u+ 1，ack = w+1)

流量控制

根据滑动窗口机制实现流量控制，接收窗口rwnd(根据自己能接受得大小)还有拥塞从窗口cwnd的最小值(既信道大小，反映当前窗口的容量)

拥塞控制

慢开始，拥塞避免，快重传、快恢复

OSI模型的第七层

应用层直接和应用程序的接口结合，并提供常见的网络应用服务
