前言

上半年遗留的问题了，一直想学完但是就是没拿出时间学，现在有时间了赶紧学

可执行文件

可执行文件分为ELF(Executable and Linking Format）文件->linux

与PE（Portable[便捷的] Executable）文件，Windows

PE文件

此文件格式是windows可执行文件、对象和dll文件的标准格式，基于MISCRosoft的它基于 Microsoft 的 COFF（Common Object File Format）规范，并添加了一些特定于 Windows 的扩展

主拓展名 种类
可执行系列 EXE、SCR(屏幕保护程序)
驱动文件系列 SYS（现代Windows（NT内核）下的标准驱动程序）、VXD
库系列 DLL、OCX(ActiveX 控件文件）、CPL、DRV(设备驱动文件)
对象文件系列 OBJ

除了obj均可以运行，DLL、SYS可以在shell直接运行(调试器、服务器执行)

OCX (OLE控制扩展)、CPL**(控制面板程序项)**本质上是特殊的DLL文件

PE文件的基本格式

DOS头
DOS存根
NT头

节区头(.data)
节区头(.rsrc)
NULL

节区(.rsrc)

dos头（标识文件类型：通过e_magic字段【通常是”MZ”，确认文件是可执行文件】，指向PE头，支持早期的DOS程序运行）

dos到节区头是PE的头文件部分，其下区合称PE体，文件中使用偏移，内存中是用虚拟地址(VA)来定位

dos存根：为了兼容MS-DOS操作系统，目的是当这个文件在 MS-DOS 上运行时提示一段文字，大部分情况下是：This program cannot be run in DOS mode. This program requires Microsoft Windows.”还有一个目的，就是指明 NT 头在文件中的位置。

NT头主要包含：NT头是个复合结构，他是由PE Signature(“PE\0\0”50 45 00 00)+COFF Header(IMAGE_FILE_HEADER映像)+Optional Header(IMAGE_OPTIONAL_HEADER)

节表示对后续节的描述

节：实际上是一个容器，可以包含代码与数据
$$
不同的开发工具与编译选选项，节区名称大小个数也不一样，主要是按照不同用途分到不同的节里
$$
PE头和节为的NULL填充区，主要起到对齐作用，使得节区在文件和内存中符合对齐要求

VA与RVA

VA是虚拟内存的绝对地址，RVA(relative virtual address)是相对地址，找到某个基址(imagBase)

RVA + imagBase = VA

PE头大多以RVA形式存在，允许重定向

PE头

DOS头

为了考虑对DOS的兼容，在最前面加上了一个 IMAGE_DOS_HEADER 结构体

结构体大小为64字节

主要两个成员一个是e_magic(DOS的签名)[前两字节]，不如是4D 5A(MZ)

e_lfanew[后4字节]指向PE头的起始位置IMAGE_NT_HEADERS 结构体

这文件e_lfnew中是0000000080(从文件开头到的偏移量)

在dnspy中可以很好的看见PE头的结构

DOS存根

大小不固定，由数据（字符串数据）和代码混合而成，提示用户仅能在Window环境中运行

NT头

签名(值为50 45 00 00， PE\0\0)、文件头(IMAGE_FILE_HEADER结构体)、可选头(PIMAGE_NT_HEADERS结构体)三件套

文件头

有下面4个主要成员：

1.Machine

每个CPU都有唯一的machine码，兼容32位Intel x86的值为0x014C

下面是winnt.h中的machine

2.NumberOfSections（值一定大于0，当定义的节区值与实际的不同时会运行错误）

PE文件将代码、数据和资源分依据属性分类到各个节区中存储，NumberOfSections代表各个节区的数量

3.SizeOfOptionalHeader

IMAGINE_OPTIONAL_HESDER结构体的大小

4.characteristics

用于标识文件的属性，文件是否可运行，是否为DLL文件等信息,characteristics是各个属性的bit or(位或的结果)

关注0x0002和0x200

可选头

1.Magic

IMAGE_NT_OPTIONAL_HDER32_MAGIC时,Magic为0x10B(可执行映像)

IMAGINE_NT_OPTIONAL_HDER64_MAGIC为0x20B(可执行映像)

2.AddressOfEntryPoint

指出程序最先进入的起始地址(有ep入口点的RVA)

3.IMAGEBASE

文件加载到内存的首选地址，此值是64k的倍数(64位系统)，dll的默认值是0x10000000,

文件类型 32 位默认值 64 位默认值
EXE 0x00400000 0x140000000
DLL 0x10000000 0x180000000
SYS 无统一标准（参考值 0x10000） 无统一标准

但是windows一般开启ASLR(地址空间布局随机化)，也就是随机选择地址进行载入

执行pe文件时pe文件先创建进程，再将文件载入内存，将eip指向imagebase+AddressOfEntryPoint进行执行

4.SectionAlignment，filealignment

sectionalignment内存加载的节的对齐方式

filealignment文件各个部分的原始数据的对齐方式

5.SizeOfImage

将pe加载到内存时，SizeOfImage指定了PE Image在虚拟内存中所占的空间大小

6.SizeIfHeaders

PE头的大小，是FileAlignment的整数倍

因此第一节区位置距离文件开始的偏移量和SizeIfHeaders相等

7.Subsystem

区分驱动文件*.sys和普通的可执行文件*.dll

值 含义 备注
1 Driver文件 系统驱动(*.sys)
2 GUI文件 窗口应用程序(ida.exe)
3 CUI文件 控制台应用程序(cmd.exe)

8.NumberOfRvaAndSizes

用来指定DataDirectory(IMAGE_OPTIONAL_HEADER32最后一个成员)数组的个数

9.DataDirectory

由IMAGE_DATA_DIRETORY结构体数组组成

每个成员包含两个 DWORD 成员，分别表示某个数据目录的 RVA 和大小

索引 winnt.h 宏 含义 说明
0 IMAGE_DIRECTORY_ENTRY_EXPORT 导出表 RVA 指向 IMAGE_EXPORT_DIRECTORY
1 IMAGE_DIRECTORY_ENTRY_IMPORT 导入表 RVA 指向 IMAGE_IMPORT_DESCRIPTOR 数组，以全 0 项结束
2 IMAGE_DIRECTORY_ENTRY_RESOURCE 资源表 以树形式组织，路径为 .rsrc，通常包含 3 层
3 IMAGE_DIRECTORY_ENTRY_EXCEPTION 异常表 x64 或 ARM 的 .pdata（RUNTIME_FUNCTION 数组）；x86 通常为空
4 IMAGE_DIRECTORY_ENTRY_SECURITY 证书表 例外：VirtualAddress 是文件偏移，不是 RVA
5 IMAGE_DIRECTORY_ENTRY_BASERELOC 基址重定位表 .reloc，指向块链结构
6 IMAGE_DIRECTORY_ENTRY_DEBUG 调试目录 IMAGE_DEBUG_DIRECTORY 数组，常见于 .debug 或 .pdata
7 IMAGE_DIRECTORY_ENTRY_ARCHITECTURE 架构保留 规范要求保留，应包含 0 项
8 IMAGE_DIRECTORY_ENTRY_GLOBALPTR 全局指针 保留，约定包含 0 项；MIPS 用过
9 IMAGE_DIRECTORY_ENTRY_TLS 线程局部存储 IMAGE_TLS_DIRECTORY
10 IMAGE_DIRECTORY_ENTRY_LOAD_CONFIG 加载配置 .rdata 中的 IMAGE_LOAD_CONFIG_DIRECTORY
11 IMAGE_DIRECTORY_ENTRY_BOUND_IMPORT 绑定导入 旧式预绑定导入，由 IMAGE_BOUND_IMPORT_DESCRIPTOR 构成，现代链接器基本不产生
12 IMAGE_DIRECTORY_ENTRY_IAT 导入地址表 IAT 本身的 RVA 和大小，常用于保护区段
13 IMAGE_DIRECTORY_ENTRY_DELAY_IMPORT 延迟导入 IMAGE_DELAYLOAD_DESCRIPTOR 数组，以全 0 项结束
14 IMAGE_DIRECTORY_ENTRY_COM_DESCRIPTOR CLR 运行时头 指向 IMAGE_COR20_HEADER；非托管 PE 中这里为 0
15 （无宏） 保留 规范要求包含 0 项

主要注意 EXPORT Directory 和 IMPORT Directory 还有 TLS Directory

节区头

节区头决定了节区的属性

类别 访问权限
code 执行，读取权限
data 非执行，读写权限
resource 非执行，读取权限

把具有相同属性的内容放在同一个节区，方便操作系统对节区的保护

Misc.physicalAddress是文件地址

Misc.virtualSize;节加载到内存中的大小

VirtualAddress内存中节区的起始地址（RVA）

SizeOfRawData磁盘文件中节区所占的大小

PointerToRawData磁盘中节区的起始位置

Characteristics节区属性

RVA to RAW

PE文件从磁盘到内存的映射

RAW是文件偏移

RVA是相对虚拟地址

RVA = VA - ImageBASE

这都是偏移

RAW - PointerToRawData = RVA - VirtualAddress

RAW = RVA - VirtualAddress(RVA) + PointerToRawData

IAT

IAT是导入地址表，保存的内容和 Windows 操作系统的核心进程、内存、DLL结构有关，记录有哪些函数
